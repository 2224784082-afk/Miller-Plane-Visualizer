# Miller Plane Visualizer

An interactive single-unit-cell Miller plane visualizer for common crystal cells.

## Features

- Enter positive or negative Miller indices `(h k l)`.
- Switch between cubic, tetragonal, orthorhombic, and hexagonal unit cells.
- Visualize the plane clipped inside one unit cell.
- Rotate, zoom, reset the 3D view, and customize plane color and opacity.
